# Task Completion Checklist

When a coding task is completed, ensure:

1. **Build passes**: `dotnet build` completes without errors
2. **Tests pass**: `dotnet test` passes on all target frameworks (net9.0, net8.0)
3. **Code style**: Follows .editorconfig rules and project conventions (see code_style.md)
4. **No regressions**: Existing tests still pass after changes
